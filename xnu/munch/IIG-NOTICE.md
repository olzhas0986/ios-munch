# Pinned IIG source snapshot

`iig-8796.tar.gz` contains 17 generated header/implementation pairs from
Apple XNU `xnu-8796.141.3`, generated by `iig(DriverKit-286)`. These are
source files, not an executable IIG or a prebuilt kernel. Their original
comments are retained unchanged. Apple source license is in `APPLE_LICENSE`.

Provenance: the public `xnu-buildtree` artifact of
https://github.com/dipa-studio/ios-sweet/actions/runs/39158169212,
`build/xnu.obj/DEVELOPMENT_ARM64_SWEET/iokit/DriverKit/`.
All 17 .iig inputs were compared byte for byte against pristine Apple XNU
commit `1b191cb58250d0705d8a51287127505aa4bc0789` before packaging.
`iig-8796.json` records every source/output digest and the archive digest.

This avoids the newer Xcode IIG output's incompatible `IORPC.kernelContent`
expectation. `tools/iig-cached.py` validates the complete .iig input set and
all input digests before writing the selected pair. It refuses changed or
unknown interfaces; it must not be used to generate new interfaces.

The workflow is deliberately fixed to ARM64 DEVELOPMENT/SWEET xnu-8796.
This snapshot is not a general replacement for Apple's generator. A kernel
build is still required on the macOS runner; local validation of the
snapshot does not establish success of that CI build or a boot on munch.
